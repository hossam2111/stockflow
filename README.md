# StockFlow

منصة عربية متعددة الشركات لإدارة مخزون الاشتراكات ومتابعة سحوبات الموظفين. تشمل تسجيل الدخول والصلاحيات، لوحة تحكم حقيقية، المخزون والاستيراد، الخدمات، الموظفين وحدود السحب، التقارير، سجل النشاط، والتخصيص الذري للحسابات من PostgreSQL.

## التشغيل

```bash
npm install
npm run db:migrate
npm run dev
```

انسخ `.env.example` إلى `.env.local` واضبط `DATABASE_URL` و`AUTH_SECRET` قبل تشغيل الترحيلات. افتح `http://localhost:3000` بعد تشغيل الخادم.

## قاعدة البيانات

- PostgreSQL (تم اختباره مع Neon).
- فصل كامل للبيانات حسب الشركة أو مساحة العمل.
- معاملات ذرية مع row-level locking لمنع تخصيص الحساب نفسه لموظفين في الوقت ذاته.
- دعم الحسابات الفردية والمشتركة والسحب المتعدد وحدود الموظف والخدمة.

## النشر على Hostinger

المشروع مناسب لخطة Hostinger VPS أو أي خطة Web App تدعم Node.js 22 وقاعدة PostgreSQL. لا يُنصح برفعه على استضافة PHP المشتركة التقليدية.

1. اضبط متغيرات البيئة اعتمادًا على `.env.example`.
2. شغل `npm ci` ثم `npm run build`.
3. شغل التطبيق بـ `npm run start` خلف Nginx أو مدير عمليات مثل PM2.
4. شغّل `npm run db:migrate` مرة واحدة على قاعدة بيانات الإنتاج.

## قرارات المنتج

- لا يوجد تسجيل ذاتي. الأدمن فقط ينشئ بريد وكلمة مرور الموظف.
- الواجهة عربية RTL ومتجاوبة وتدعم الوضع الداكن.
- تدفق السحب مصمم كعملية سريعة بتخصيص آلي، مع عرض حدود الموظف.
- بيانات الحسابات لا تظهر للموظف إلا بعد تنفيذ عملية السحب المصرح بها.
- اختيار المخزون وتسجيل السحب يتمان من الخادم داخل transaction واحدة.
